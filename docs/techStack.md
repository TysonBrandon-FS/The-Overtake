# Tech Stack

## WordPress

WordPress is the main platform for The Overtake. It is used to manage the site pages, media, plugins, theme settings, and overall website structure.

## Elementor

Elementor is used to build the visual layout of the site. I will use it for the homepage, shop page, product sections, and responsive design edits.

## WooCommerce

WooCommerce is used for the eCommerce side of the project. It handles products, pricing, cart, checkout, and store settings.

## Printify

Printify is the print provider for the merch. It will be used for product mockups, print on demand production, fulfillment, and shipping.

## WooPayments

WooPayments is used for checkout and payment processing. Any private payment settings or keys will stay inside WordPress and will not be committed to GitHub.

## Custom Code

Custom code will be saved in the `custom-code` folder. This may include HTML, CSS, JavaScript, PHP snippets, or code copied from Elementor widgets so GitHub can track it.

## Theme Files

The `theme` folder is reserved for child theme files if needed. This would include files like `functions.php` and `style.css`.

## GitHub

GitHub is used to track project documentation, screenshots, exports, custom code, and progress. I will use feature branches for major updates.

## Activity Log Plugin

An activity log plugin will help track WordPress admin changes that GitHub cannot see directly, like Elementor edits, plugin updates, and dashboard changes.

## Tracking Plan

Since WordPress stores many changes in the database, I will track progress with GitHub commits, screenshots, exports, notes, and activity logs. and build a custom tracking plugin for Elementor.
